# Instruction design criteria — toolkit walkthroughs

**Derived from:** instructional design practice, `baoyu-infographic/references/analysis-framework.md`, education rubric v3  
**Pass:** all **must** items satisfied; **should** items ≥ 80%

## Must (fail if missing)


| ID  | Criterion                         | Evidence on page                                                               |
| --- | --------------------------------- | ------------------------------------------------------------------------------ |
| M1  | **Verifiable learning objective** | `toolkit-outcome` — "After this walkthrough you will have…"                    |
| M2  | **Prerequisites stated**          | `toolkit-prereq` — time, tools, access                                         |
| M3  | **Chunked sequence**              | Numbered `toolkit-phase-grid` or `toolkit-method`; one primary action per step |
| M4  | **Worked example**                | Copy-paste command or concrete path in ≥ 1 step                                |
| M5  | **Feedback signal**               | `toolkit-phase-exit` or expected output per step                               |
| M6  | **Error recovery**                | `toolkit-phase-fix` per step + `toolkit-pitfalls`                              |
| M7  | **Transfer artefact**             | Download under `toolkits/artefacts/<slug>/`                                    |
| M8  | **Cognitive load control**        | Section ledes; no wall of prose without TOC break                              |


## Should (target 100%)


| ID  | Criterion            | Evidence                                         |
| --- | -------------------- | ------------------------------------------------ |
| S1  | Before/after value   | `toolkit-compare` tied to real workflow          |
| S2  | Audience fit         | `toolkit-roles` or start panel "who this is for" |
| S3  | Curated depth path   | `toolkit-curated-table` ≥ 3 with *why*           |
| S4  | Self-assessment hook | Checklist reader can tick                        |
| S5  | Honest scope limit   | Pitfalls or when-not-to-use                      |


## Cognitive load rules

- Max **one** new concept per step title  
- Commands in `toolkit-terminal` — not inline paragraph soup  
- Jargon allowed only with plain-language gloss in same sentence  
- Diagram: **one** primary `toolkit-artefact-figure` per page

## Hermes scoring

Count must-pass: **8/8** required.  
Should-pass: **≥ 4/5** for instruction-design layer PASS.
