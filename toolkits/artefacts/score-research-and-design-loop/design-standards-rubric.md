# Design output rubric (starter template)

**Version:** 1.0 - replace after your workshop  
**Pass threshold:** 14 / 16 (adjust if you use more or fewer rows)

Score each row **0-2**:

| # | Dimension | What "2" looks like |
|---|-----------|---------------------|
| 1 | **Intent** | User job, success metric, and scope boundary |
| 2 | **Acceptance criteria** | At least 3 pass/fail checks |
| 3 | **Design system fit** | Components, tokens, or patterns named |
| 4 | **Evidence attached** | Wireframe, Figma frame, or spec link included |
| 5 | **Accessibility** | Focus, labels, contrast, or WCAG target stated |
| 6 | **Edge states** | Empty, error, loading, or denied covered |
| 7 | **Revision path** | How to undo or iterate is documented |
| 8 | **Review readiness** | Approver knows what "done" means |

## How to use

1. Customize rows in the workshop. Do not ship this file unchanged.
2. Save next to your research rubric using the same folder convention.
3. Score before design critique, stakeholder review, or handoff to build.
4. Pair with the research rubric when design follows a study.

## When you score below the pass bar

- **Rows 1-2 weak:** Review will become opinion. Rewrite acceptance checks first.
- **Row 4 at 0:** No file to review. Add wireframe or frame link before sharing.
- **At or below 13/16:** Fix scope or edge cases, not prompt length alone.
