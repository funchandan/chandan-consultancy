How it works

How to use these

  1. Pick a walkthrough that matches where you are (BMAD setup, Hermes cron, skills audit).
  2. Run the commands in your repo — every step maps to real upstream tooling.
  3. Download artefacts (Excalidraw, YAML, checklists) and adapt them to your programme.

Education over invention: each page is a runnable process or stack setup with downloads you can adapt. See the review loop if you publish similar pages on your own site.

Need help applying this stack?

I run these same flows on enterprise programmes — the walkthroughs are the open-source version.
