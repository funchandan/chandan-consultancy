# Sketch 003: Nav Search Trigger

## Design Question

How does the glass search relocate to the nav pill without crowding Work / Method / Connect / CV?

## How to View

```bash
open .planning/sketches/003-nav-search-trigger/index.html
```

## Variants

- **A: Icon expand** — Search icon in pill; click expands inline field between links and CV CTA
- **B: Persistent slim slot** — Narrow search field always visible between Connect and CV
- **C: Overlay drawer** — Search icon opens full-width overlay below nav; pill width stays stable

## What to Look For

- Does search feel discoverable without dominating the pill?
- Mobile: does the pattern survive 375px width?
- Expanded state: placeholder rotation + category chips still usable?

## Checkpoint

**Winner: C — Overlay drawer** (locked 2026-06-30)
