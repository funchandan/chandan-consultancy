# Sketch 001: Toolkit Proof Hero

## Design Question

How should proof metrics (rubric scores, artefact thumbnails, registry counts, cron status) coexist with the walkthrough card without feeling like a dashboard?

## How to View

```bash
open .planning/sketches/001-toolkit-proof-hero/index.html
```

## Variants

- **A: Metrics rail** — Walkthrough card left ~70%; vertical proof rail right (scores, cron, registry)
- **B: Artefact gallery** — Large artefact thumbnail + score badge above steps; registry/cron as footer chips
- **C: Scorecard header** — Compact proof band across top; walkthrough body below

## What to Look For

- Does proof feel like *receipts for the active walkthrough* (not generic stats)?
- Is the SHIP card ("Personal Hermes AI stack") still the emotional anchor?
- Can you read steps + metrics at a glance without scanning a dashboard?

## Checkpoint

**Winner: B — Artefact gallery** (locked 2026-06-30)
