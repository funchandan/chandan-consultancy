# Sketch 002: Reviews + Quiz Split

## Design Question

What column split balances social proof (reviews left) vs interactive quiz (sortable list right)?

## How to View

```bash
open .planning/sketches/002-reviews-quiz-split/index.html
```

## Variants

- **A: Sidebar (1:2)** — Reviews ~33%, quiz ~67%. Single quote + avatar, prev/next.
- **B: Narrow strip (1:3)** — Reviews ~25%, quiz ~75%. Quote clamped 3 lines, no avatar stack.
- **C: Balanced compact (1:1)** — Equal columns; reviews stay visually small via typography.

## Mobile (all variants)

Toolkit → Reviews → Quiz (single column).

## What to Look For

- Does the quiz feel like the primary interaction without reviews feeling like an afterthought?
- Is the reviews cell readable at narrow widths (variant B)?
- Does 1:1 (variant C) waste space or feel editorial?

## Checkpoint

**Winner: B — 1:3 narrow strip** (locked 2026-06-30)
